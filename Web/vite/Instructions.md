# vite.config.js

## Установка:

### Через npm (идет вместе с Node.js)
```bash
npm install vite
```

### Через yarn
```bash
yarn install vite
```

## Использование:

### После установки просто поместите файл в главную папку проекта. Vite автоматически будет использовать параметры из конфига.

## Запуск:

### Для запуска сайта локально используйте команду:
```bash
npm run dev
```

## Сборка

### Чтобы собрать сайт для использования на сервере, используйте команду:
```bash
npm run build
```
### Убедитесь что в настройках сервера установлена таже папка что и в конфиге.
